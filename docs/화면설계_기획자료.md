## 5. 일괄안내 — `/app/campaigns` (`guide__Meta_DS_.html`)

**3개 화면 흐름**: A 목록 → B 작성(3스텝 마법사) → C 집계

**A 목록**: 헤더(+[새 캠페인]) + 테이블: 제목 | 세그먼트 요약(칩) | 대상 수 | 발송일 | 응답률 | 상태(발송완료=`st-sent` / 예약됨=파랑 soft / 임시저장=중립). 빈 상태 "첫 캠페인을 만들어보세요".

**B 작성 마법사** — 스텝 인디케이터(①세그먼트 ②메시지 ③발송 확인, 완료=체크/활성=cobalt)
1. **세그먼트**: 조건 빌더(필드+연산자+값 행, AND/OR 토글, [+조건 추가]) + 우측 실시간 미리보기("N개사 대상" 기업 목록 / 0건이면 경고)
2. **메시지**: 알림톡 템플릿 선택 + 변수 칩(`{기업명}` `{담당자명}` — dashed 보더) + 본문 textarea + 우측 폰 미리보기(버블)
3. **발송 확인**: 요약 3열(대상/채널/템플릿) + 발송 시점 라디오(즉시/예약+일시) + 대상 최종 목록
- 푸터: [이전]/[다음] · 마지막 스텝 [예약 발송]+[발송](cobalt) → 발송 토스트(스피너→완료)

**C 집계**: [← 일괄안내] + 제목 + 상태 배지 + KPI 4열(발송/도달/응답/응답률-primary 강조) + 기업별 응답 테이블(도달·응답 yes/no 도트 배지 + 응답 내용 + 시각)

**데이터**: campaign(segment jsonb, status) / campaign_recipient(delivered, responded, response_note)
